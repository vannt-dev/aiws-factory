**Language:** English · [Tiếng Việt](README.vi.md)

AIWS turns a requirement into tested code through controlled phases with human gates:
analysis → design + test spec → **human approval** → per-task implementation with unit tests → review → **human PR merge** → knowledge update.
A deterministic orchestrator owns the state; AI agents only work inside the write scope of the current phase.
V1 runs on Claude Code and works with any language in the frontend, backend or legacy code.

**Landing page:** https://vannt-dev.github.io/aiws-factory/

## Workspace layout

```
requirements/         input requirements (written by people)
source-fe/            target frontend repository (any language)
source-be/            target backend repository (any language)
source-legacy/        legacy system, read-only
aiws/                 rules, agents, skills, templates, knowledge, work, orchestrator CLI
AGENTS.md             rules shared by every AI tool
CLAUDE.md, .claude/   generated by `aiws sync claude`, do not edit by hand
```

## Quick start

Requirements: Node.js ≥ 22, Git, and Claude Code signed in. Works on **Windows, macOS and Linux** (all three run in CI);
build/test commands can differ per OS (`{windows: ..., posix: ...}` in `policies.yaml`).

```bash
cd aiws/adapters/cli && npm install && npm link && cd ../../..
aiws detect --write      # recognise the stack of each source-* folder
aiws sync claude         # generate CLAUDE.md and .claude/
aiws discover            # build aiws/knowledge/
aiws new REQ-001 && aiws run REQ-001
```
