Từ requirement tới code đã test, có kiểm soát.

AIWS (AI Software Factory) điều phối AI đi qua các phase rõ ràng: phân tích, thiết kế kèm test spec, code từng task nhỏ kèm unit test, rồi review. Mỗi bước bị giới hạn phạm vi ghi, mọi output nằm trong git, và con người duyệt ở những điểm quan trọng.

Kiến trúc

Ba lớp tách biệt

Đổi AI không phải viết lại quy trình. Thêm Codex hay Gemini chỉ là thêm một adapter.

Corelàm gì

Agent, skill, workflow, contract, policy dưới dạng Markdown/YAML trong aiws/, trung lập với mọi AI. Người sở hữu và review như code.

Orchestratorkhi nào được làm

CLI aiws giữ state.yaml, chạy phase, kiểm contract, so diff-scope, chạy build/test thật, commit kèm trailer truy vết.

Adapterlàm bằng AI nào

claude chạy Claude Code headless với quyền giới hạn; scripted chạy tất định để test không tốn token. V2: Codex, Gemini, review chéo giữa các model.

Bảo vệ

Gate được chặn bằng cơ chế thật, không chỉ bằng prompt

Bốn lớp độc lập. Một lớp bị vượt qua thì lớp sau vẫn chặn.

01

Orchestrator

Không gọi agent của phase bị khoá. Approval gắn hash nội dung, retry có giới hạn.

02

Quyền tool

Mỗi lần chạy headless chỉ cấp đúng tool cần. Lệnh shell được suy ra từ lệnh build/test của dự án.

03

Hook guard

PreToolUse chặn ghi ngoài phạm vi phase, chặn đọc bí mật, chặn AI tự approve, kể cả lệnh lồng.

04

Git + diff-scope

Sau mỗi lần chạy, mọi file bị sửa ngoài phạm vi đều bị revert và lần chạy bị đánh fail, dù được ghi bằng cách nào.

Đa ngôn ngữ

FE, BE, legacy viết bằng gì cũng được

Orchestrator không giả định stack. aiws detect nhận diện từng thư mục source-* và đề xuất lệnh build/test; thêm bao nhiêu side cũng được (fe, be, mobile, worker...).

  • Tự nhận diện stack: Maven, Gradle, .NET, npm/pnpm/yarn, Python, Go, PHP, Ruby, Rust, Dart/Flutter.
  • Legacy chỉ đọc: thống kê ngôn ngữ (vd. .cbl, .frm) đưa vào discovery.
  • Truy vết mọi framework: mã TC-3 gắn qua @DisplayName, [Trait], pytest.mark, t.Run...

Chuẩn quốc tế

Output theo chuẩn thông dụng, không phá cấu trúc

Ưu tiên convention sẵn có của dự án, sau đó tới style guide chính thống của ngôn ngữ. Đổi tên, di chuyển hay reformat ngoài design đã duyệt đều bị reviewer đánh lỗi.

Bắt đầu

Chạy trong vài lệnh

Yêu cầu Node ≥ 20, Git và Claude Code đã đăng nhập. Đưa code vào source-fe/, source-be/, source-legacy/, rồi:

  • Lệnh của người (approve, reject, answer, resume) từ chối chạy trong phiên AI.
  • Chạy song song nhiều REQ ở phase analysis/design qua aiws new --worktree.
  • Không tốn token khi test: adapter scripted chạy toàn bộ quy trình tất định.
# cài CLI
$ cd aiws/adapters/cli && npm install && npm link

# nhận diện stack, sinh cấu hình Claude, lập bản đồ
$ aiws detect --write
$ aiws sync claude
$ aiws discover

# một requirement
$ aiws new REQ-001
$ aiws run REQ-001            # dừng ở gate design
$ aiws approve REQ-001 design
$ aiws run REQ-001            # dừng ở gate PR
$ aiws approve REQ-001 pr     # sau khi merge
$ aiws run REQ-001 && aiws trace REQ-001
